# Screenshot Assets

This folder is reserved for public GitHub screenshots used by `README.md`,
release notes, and issue discussions.

## Expected Files

- `main-window.png` - Open Windows page with a realistic set of normal apps.
- `settings.png` - Settings page showing General, Appearance, Language, Startup,
  Tray, Hotkeys, Safety, and About sections.
- `managed-windows.png` - Managed Windows page with grouped cards and restore
  actions visible.
- `tray-menu.png` - Windows system tray menu with Open ShelfyGAI, Restore All
  Windows, Settings, and Quit.
- `language-switch.png` - Settings page with the language selector visible.

## Recommended Sizes

- Primary README screenshots: `1600x1000` or `1440x900`.
- Wide hero/preview crops: `1920x1080`.
- Tray menu screenshots: `900x700` or smaller, cropped around the tray menu.
- High DPI capture is welcome, but export final PNGs at a readable 1x or 2x
  size so GitHub renders them cleanly.

## Capture Guidance

- Use Windows 11 dark mode when possible.
- Use ShelfyGAI's dark theme and a non-default accent color only when showing
  customization.
- Avoid showing personal file paths, private window titles, usernames, emails,
  browser tabs, or notifications.
- Prefer ordinary productivity apps such as Notepad, Terminal, Calculator, or a
  browser on a neutral page.
- Keep the taskbar visible for the main screenshot so the utility's purpose is
  immediately understandable.
- Verify text is readable at GitHub README width before committing images.

## Suggested Scenario

1. Start ShelfyGAI from source or packaged build.
2. Open a few safe, ordinary desktop windows.
3. Capture the Open Windows page before hiding anything.
4. Hide two or three windows into a group.
5. Capture the Managed Windows page.
6. Open Settings and capture appearance/language controls.
7. Open the tray menu and capture the available actions.
