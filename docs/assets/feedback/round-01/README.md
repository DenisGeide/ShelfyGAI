# Feedback Round 01 Assets

This folder is reserved for screenshots from the first ShelfyGAI UI review.

Do not create fake screenshots. Add only real screenshots captured from the app,
Windows taskbar, tray overflow, or installer files that were reviewed during the
first feedback round.

## Expected Screenshots

| Screenshot | Purpose |
| --- | --- |
| `01-current-main-ui.png` | Current main UI showing visual density and unclear first-time workflow. |
| `02-current-pinned-list.png` | Current pinned windows list showing ordering and pin behavior concerns. |
| `03-current-tray-overflow.png` | Windows tray overflow showing why tray visibility needs clear limitations. |
| `04-current-taskbar.png` | Windows taskbar showing clutter and the need for clear hidden-window/group behavior. |
| `05-current-installer-files.png` | Installer folder/files showing why the user-facing installer path must be simple. |
| `06-current-groups-sidebar.png` | Current groups sidebar showing unclear icon-only group actions. |

## Usage

- Store the original feedback screenshots here before publishing the release
  branch or issue discussion.
- Keep filenames exactly as listed above.
- Avoid embedding large images directly in Markdown feedback documents.
- Reference images with relative links from `docs/FEEDBACK_ROUND_01.md`.
- Do not include private desktop data, usernames, account details, browser tabs,
  notifications, or unrelated personal content.
