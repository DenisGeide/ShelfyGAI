# Code of Conduct

## Our Pledge

We want ShelfyGAI to be a welcoming, practical, and respectful open-source
project. Contributors and users are expected to participate with care for each
other and with respect for user privacy and desktop safety.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially when discussing bugs or platform limitations.
- Keep feedback focused on the work, not the person.
- Protect private data in examples, logs, screenshots, and issue reports.
- Help maintain ShelfyGAI's local-first, no-telemetry project values.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Sharing another person's private information without consent.
- Posting logs or screenshots that expose private window titles, file paths, or
  usernames without a clear need and appropriate redaction.
- Pressuring maintainers to add telemetry, advertising, cloud sync, or
  surprising background behavior.
- Repeatedly disrupting discussions after maintainers ask for a change in tone
  or direction.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or
limit participation when behavior harms the project or its contributors. Serious
or repeated violations may lead to a ban from project spaces.

## Reporting

Report conduct concerns privately through the maintainers' published contact
channels or GitHub moderation tools. Please include relevant links or context.
Maintainers will review reports with discretion and avoid sharing private
details beyond what is needed to respond.

## Scope

This code of conduct applies to ShelfyGAI project spaces, including GitHub
issues, pull requests, discussions, documentation, and community channels.
