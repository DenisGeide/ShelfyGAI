# ShelfyGAI Windows Installer

ShelfyGAI uses Inno Setup to produce a standard Windows installer around the
standalone PyInstaller executable.

## Prerequisites

- Windows 10 or Windows 11
- Python 3.11+
- Project build dependencies installed
- Inno Setup 6 installed

Install Inno Setup from the official site, then make sure `ISCC.exe` is
available either in `PATH` or through the default install location:

```powershell
$env:Path += ";" + (Join-Path ([Environment]::GetFolderPath("ProgramFilesX86")) "Inno Setup 6")
```

## Build the PyInstaller Executable

From the repository root:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[build]"
.\scripts\build_exe.ps1 -Clean
```

Expected output:

```text
dist\ShelfyGAI\ShelfyGAI.exe
build\assets\app_icon.ico
```

The installer script expects the full `dist\ShelfyGAI\` folder and generated
icon to exist. The icon is generated by the PyInstaller build script from
`src\shelfygai\resources\app_icon.svg`.

## Build the Installer

From the repository root:

```powershell
.\scripts\build_installer.ps1 -SkipExeBuild
```

Expected output:

```text
dist\installer\ShelfyGAI-Setup-0.1.0.exe
```

## Build the One-File Web Installer

For the simplest user download, build the small web installer after the full
offline installer has been attached to a GitHub release:

```powershell
Get-FileHash .\dist\installer\ShelfyGAI-Setup-0.1.0.exe -Algorithm SHA256
.\scripts\build_web_installer.ps1 `
  -DownloadUrl "https://github.com/shelfygai/shelfygai/releases/download/v0.1.0/ShelfyGAI-Setup-0.1.0.exe" `
  -DownloadSha256 "<64-character-sha256>"
```

Expected output:

```text
dist\installer\ShelfyGAI-WebSetup-0.1.0.exe
```

This file downloads and launches the full offline installer. See
`installer\README_WEB_INSTALLER.md`.

## Install Behavior

- Uses Inno Setup's automatic Program Files/user-local install directory.
- Allows the user to choose an all-users or current-user install when supported.
- Creates a Start Menu shortcut.
- Offers an optional desktop shortcut.
- Adds standard Windows uninstall support.
- Offers to launch ShelfyGAI after install.
- Does not enable Windows autostart during installation.
- Does not install any service.

## User Data Preservation

The installer only installs application files under `{app}`. It intentionally
does not remove or migrate user data in:

```text
%APPDATA%\ShelfyGAI\
```

That directory contains settings, logs, and recovery state. It is preserved
across installs, upgrades, repairs, and uninstall/reinstall cycles.

- `src\shelfygai\__init__.py`
- `pyproject.toml`
- `packaging\windows\version_info.txt`
- `installer\ShelfyGAI.iss`
- `CHANGELOG.md`
